# Font Files

Please download and place the following font files in this directory:

## Pretendard (Korean Font)
- **File**: `PretendardVariable.woff2`
- **Source**: https://github.com/orioncactus/pretendard/releases
- **Usage**: Main font for Korean text

## Roboto Mono (Code Font)
- **File**: `RobotoMono-VariableFont_wght.ttf`
- **Source**: https://fonts.google.com/specimen/Roboto+Mono
- **Usage**: Monospace font for code blocks

## Download Instructions

1. **Pretendard**:
   - Visit: https://github.com/orioncactus/pretendard/releases
   - Download the latest release
   - Extract and find `PretendardVariable.woff2` file
   - Place it in this directory

2. **Roboto Mono**:
   - Visit: https://fonts.google.com/specimen/Roboto+Mono
   - Click "Download family"
   - Extract and find `RobotoMono-VariableFont_wght.ttf` file
   - Place it in this directory

After downloading, your fonts directory should look like:
```
src/app/fonts/
├── PretendardVariable.woff2
├── RobotoMono-VariableFont_wght.ttf
└── README.md
```
